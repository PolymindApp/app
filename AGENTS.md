# Project Instructions

Before working on any task in this repository, load and follow these skills in order:

1. Read `skills/shared/default/SKILL.md` completely and apply its project-wide conventions.
2. Read `skills/local/SKILL.md` completely and apply its Mom-specific UI direction.

Treat both skills as repository instructions. When their guidance overlaps or conflicts, apply the local skill after the shared skill so `skills/local/SKILL.md` takes precedence.

If the shared skill is unavailable because the submodule has not been initialized, run `git submodule update --init --recursive` before continuing.
